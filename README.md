A responsive recreation of the uploaded 20.77-second screen recording.

## What's in the video

The video is titled **Navigation Tabs Animation** and shows three versions of the same five-item navigation:

1. **RED NAVIGATION** — red pill-shaped bar with a soft circular active background.
2. **DARK WAVE NAVIGATION** — near-black pill with a neon-red orbit/ring around the active item and a small red indicator dot.
3. **WHITE MINIMAL NAVIGATION** — white pill-shaped bar with a red circular active background.

Each bar contains the same five icons and labels, in order:

- Home
- Search
- Create
- Inbox
- Saved

The page background is pale blush pink. The heading is `Navigation Tabs` with `Animation` below it. A small red notification dot appears on Inbox.

## Run

1. Extract this ZIP.
2. Open `index.html` in Chrome, Firefox, Safari, or Edge.
3. Click any item in any of the three navigation bars. Each bar works independently and animates its active indicator.

No build tools, packages, or server are required.

## Project files

- `index.html` — semantic page markup and inline SVG icons
- `style.css` — all three visual styles, transitions, responsive rules
- `script.js` — active-tab interaction and indicator positioning

## Extraction note

The recording shows the rendered interface and its interactions, not a readable full source-code editor. Therefore, the labels, order, icon concepts, colors, visual layout and animation behavior were recreated from the screen. The HTML/CSS/JavaScript in this project is a complete working implementation, not a byte-for-byte extraction of hidden original source.
